# D19 - Contratto backend per check-in brevi

## Obiettivo

Permettere all'app paziente di inviare risposte brevi in modo strutturato, cosi' il
backend non riceve testo libero difficile da analizzare. Questo serve per check-in
ripetibili come:

```text
Come ti senti oggi?
Hai avuto capogiri?
Hai assunto la terapia?
Hai dormito bene?
Hai dolore? Da 0 a 10 quanto?
```

## Tipi domanda supportati

Il backend valida questi tipi:

```text
yes_no
scale
single_choice
text
```

Regole:

- `yes_no`: accetta booleani oppure stringhe tipo `yes`, `no`, `si`, `sì`;
- `scale`: accetta numeri dentro `min` e `max`;
- `single_choice`: accetta solo valori presenti in `options`;
- `text`: accetta testo.

Se una risposta non rispetta lo schema, il backend restituisce errore `422` e non salva
il risultato.

## Invio risultati

L'app continua a usare l'endpoint gia' esistente:

```text
POST /api/v1/tasks/{task_id}/results
```

Payload esempio:

```json
{
  "patient_id": "patient-001",
  "started_at": "2026-07-16T08:01:00Z",
  "completed_at": "2026-07-16T08:03:00Z",
  "duration_seconds": 120,
  "device_info": {
    "device_id": "android-test",
    "platform": "android"
  },
  "answers": [
    {
      "question_id": "mood",
      "value": 7
    },
    {
      "question_id": "dizziness",
      "value": false
    }
  ]
}
```

Il backend salva:

- durata compilazione;
- `device_id` dentro `device_info`;
- risposte normalizzate;
- score quando il template ha una regola di scoring;
- risultato collegato al task concreto.

## Scoring semplice

Per ora e' supportato:

```text
scale_average
```

Esempio:

```json
{
  "type": "scale_average",
  "question_ids": ["mood", "pain"]
}
```

Il backend calcola la media delle risposte numeriche indicate. Questo basta per check-in
dimostrativi come benessere o dolore su scala 0-10.

## Eventi realtime

Quando un task viene completato, il backend continua a pubblicare:

```text
task_completed
```

Se il task deriva da un questionario strutturato, pubblica anche:

```text
questionnaire_completed
```

Questo permette alla dashboard di aggiornare sia la lista attivita' sia il futuro centro
valutazioni.

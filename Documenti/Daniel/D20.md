# D20 - Supporto dati per report e audit leggero

## Obiettivo

Fornire alla dashboard un endpoint unico per costruire un report stampabile/esportabile
senza fare molte chiamate fragili al backend.

Il report resta uno strumento di supporto al triage, non una diagnosi automatica.

## Endpoint aggiunto

```text
GET /api/v1/patients/{patient_id}/report-data
```

Parametro opzionale:

```text
days=7
```

L'endpoint e' accessibile solo a:

```text
doctor
admin
```

Il ruolo `patient` e il ruolo `caregiver` ricevono `403`.

## Contenuto del payload

Il payload contiene:

- dati essenziali paziente;
- stato corrente;
- riepilogo 24 ore;
- routine ambientale;
- decisioni AI recenti;
- alert recenti;
- task/check-in recenti;
- timeline compatta;
- note medico da task e risoluzioni alert;
- dicitura di supporto al triage;
- blocco privacy con dati esclusi.

Esempio struttura:

```json
{
  "schema_version": 1,
  "report_type": "patient_triage_summary",
  "generated_at": "2026-07-16T10:00:00Z",
  "generated_by": {
    "user_id": "user-1",
    "role": "doctor",
    "display_name": "Medico Demo"
  },
  "patient": {
    "patient_id": "patient-001",
    "display_name": "Paziente Demo"
  },
  "range": {
    "start": "2026-07-09T10:00:00Z",
    "end": "2026-07-16T10:00:00Z",
    "days": 7
  },
  "disclaimer": "Report di supporto al triage: la valutazione finale resta al medico.",
  "sections": {
    "current": {},
    "summary_24h": {},
    "spatial_summary": {},
    "recent_decisions": [],
    "recent_alerts": [],
    "recent_tasks": [],
    "timeline": [],
    "medical_notes": []
  },
  "privacy": {
    "excluded": [
      "password_hash",
      "refresh_token",
      "access_token",
      "fcm_token",
      "google_oauth_token",
      "client_secret"
    ],
    "contains_raw_sensor_payloads": false
  }
}
```

## Audit

Ogni richiesta valida scrive un evento in `audit_logs`:

```text
action = patient_report.exported
target_type = patient_report
target_id = patient_id
```

Nei dettagli vengono salvati:

- numero di giorni richiesto;
- timestamp generazione;
- sezioni incluse.

Non vengono salvati token o segreti.

## Privacy

Il report non espone:

- password o hash password;
- access token;
- refresh token;
- token FCM;
- token Google Health/OAuth;
- client secret.

Il payload usa dati aggregati e serializzazioni pubbliche gia' usate dalla dashboard.

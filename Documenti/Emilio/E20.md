# E20 - Report sintetico esportabile

## Cosa e' stato fatto

E' stata aggiunta la pagina "Report" nella Dashboard medico. La pagina crea una vista stampabile con dati principali del paziente, indice AI, ultimo aggiornamento, decisioni recenti, alert e task.

Endpoint usato:

`GET /api/v1/patients/{patient_id}/report-data`

Il pulsante "Esporta PDF" usa la stampa del browser, cosi' durante la demo e' possibile salvare il documento come PDF senza librerie aggiuntive.

## Collegamento con Daniel

Il backend D20 fornisce un payload gia' composto per il report e registra audit lato server. Se l'endpoint non e' disponibile, la Dashboard usa i dati gia' caricati localmente come fallback.

## Test consigliato

1. Aprire la pagina "Report".
2. Verificare dati correnti, decisioni e alert recenti.
3. Cliccare "Esporta PDF".
4. Salvare da browser come PDF.
5. Verificare che non compaiano token o segreti tecnici.
